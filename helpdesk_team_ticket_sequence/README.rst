helpdesk_team_ticket_sequence
-----------------------------

Sets up automatically custom number assignment for helpdesk tickets.

On installation creates custom sequence, and sets it to every helpdesk team available.

You can edit this sequence record, after which assign numbers to every ticket that has no number.

SETUP:

1. Install module, change ticket sequence to whatever needs you have.

2. Get into helpdesk teams in debug mode, press on
   "Assign Sequence To Tickets Without Numbers" button if you want
   to assign numbers to tickets without numbers
3. Further ticket numbers will be assigned automatically on ticket creation.
