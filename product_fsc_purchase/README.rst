====================
product_fsc_purchase
====================

Prints FSC claims on purchase orders and requests for quotation.

Features
========

* FSC claim block on the purchase order and request for quotation reports.
* Each line keeps the claim it was created with, so reclassifying a product
  doesn't change issued documents. Vendor bills take the claim from the order.
* Optional **FSC Claim** column on order lines.
