=====================================================
Website Helpdesk Ticket Create Ticket Type Properties
=====================================================

Glue module between `website_helpdesk_ticket_create` and `helpdesk_ticket_type_properties`.

Adds `ticket_type_properties` to `portal_helpdesk_ticket_create`

The intended workflow is that dynamic questions will be generated based on the ticket type. The information inputted by the user will be propagated to `ticket_type_properties` on the `helpdesk.ticket` record.
