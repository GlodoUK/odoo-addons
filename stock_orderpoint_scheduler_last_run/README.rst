===================================
Stock Orderpoint Scheduler Last Run
===================================

Shows when the stock scheduler last ran ("Last ran 3 hours ago", exact time on
hover) in the Replenishment report's side panel, under *Horizon*.

It counts runs from the cron and from *Run Scheduler* alike. A run that fails
isn't counted.

Known issues
============

- Like *Horizon*, it isn't shown on small screens.
