sale_action_confirm_send
========================

Add a new header button to orders in Quotation and Quotation Sent state

The button will send the order confirmation email to the customer and confirm the order.

This reduces the default two-step process of confirming the order and sending the confirmation email to a single step.

Why not base_automation?

Allows all Sales users to manually choose whether to send the confirmation email and confirm the order in a single step, without needing to self-manage an automated action.
