Stock Inventory Reason
======================
In Inventory > Operations > Physical Inventory, the per-line "Apply" button
opens the same "Inventory Adjustment" wizard as "Apply All", so the user is
always prompted for an inventory reason and counting date.

Company settings
----------------
In Inventory > Configuration > Settings > Traceability:

* **Use fixed inventory adjustment reasons**: the wizard shows a dropdown of
  Inventory Adjustment Reasons (Inventory > Configuration) instead of a free
  text field. The selected reason populates the core inventory reason.
* **Require inventory adjustment reason**: the reason (dropdown or text) must
  be filled in before the adjustment can be applied.
